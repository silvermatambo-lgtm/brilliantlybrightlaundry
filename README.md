# Brilliantly Bright Laundry

Professional laundry, dry cleaning, ironing, alterations, shoe repair and carpet cleaning.

Website: https://www.brilliantlybrightlaundry.co.za  
WhatsApp / Call: +27 72 547 5041

Built with React 18 + TypeScript + Vite + Tailwind CSS (WebDevPro Ultra Max 5 template).

## Development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
```

## Vercel
Framework = Vite, Build = `npm run build`, Output = `dist`.
